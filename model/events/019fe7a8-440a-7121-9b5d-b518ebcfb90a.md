## Notes

RECOVERED BY THE RE-SWEEP. The capped sweep named it "ReturnPathApproximatedFromOriginator" and folded it into a field, writing "split on that field if the ladder needs its own cards" — it does, and this is the split. Strength: LOWERCASE "must" at line 1637, NOT the RFC 2119 keyword. That is the chapter's third lowercase near-miss, after §2.3.10 line 823 and Appendix E line 5138; the §3.6-3.7 sweep flagged two of them in extras.md as a pattern rather than a slip, and the third confirms it. A citation from memory would report all three as normative and overstate every one — AGENTS.md rule 3's failure mode in its natural habitat. Why it is a separate event and not a variant: this rung produces a return path that is a GUESS, and everything downstream treats it as authoritative under the §4.4 MUST, so the provenance is the fact worth recording. Note the ladder has a middle rung the RFC does not name a source for — "a best approximation" — which is a 🟥 hotspot: the spec requires a choice and gives no rule for making it. Rejected alternative names: ReturnPathApproximatedFromOriginator, BestApproximationReturnPathSelected. Which project screen would have killed it: inbound-only scope; the "one event per command" target, since no command corresponds.

FIELD HYGIENE PASS: struck two fields. (1) message_ref (example f2C8D14) — no message identifier exists in RFC 5321; the return path this rung produced is the fact and the identity. (2) approximation_basis (example "message originator's address, default of last resort") — it restates the event's own name and meaning word for word from line 1637, which is padding by the method's rule, not payload. The provenance the note calls "the fact worth recording" is carried by the event NAME, which is exactly what a distinct event name is for; that is why the split from EnvelopeReturnPathSetAtGateway was right and why the field is now redundant. Also corrected return_path from \<Jones@foo.com> (the walk scene's recipient) to \<Smith@bar.com> (its reverse-path), for consistency with the same correction on EnvelopeReturnPathSetAtGateway.
