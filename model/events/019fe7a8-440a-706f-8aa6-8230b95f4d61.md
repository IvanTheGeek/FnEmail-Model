## Notes

Merged from inherited candidate SmtpServiceStarted; no rival name found in the raw set. SHOULD strength for the standing listen. The purest example of a precondition nobody writes down: you cannot shut down a service that never started, so §3.8's shutdown clause presupposes this. Rejected alternative names: ListenerBound, ServiceStarted, SmtpListenerOpened. stream_root invented — Server Configuration is a settings root and this is a runtime-instance fact about a process, so 'SMTP Service Instance' is coined here and shared with ServiceShutdownDetected and ServiceForciblyShutDown. Screens that would have killed it: the four altitude tiers rule listen_address and listen_port Infrastructure by G4; server_domain survives, since the 220, 221 and 421 lines all carry it. It is also evidence for Shape A of the model's undecided ServiceConfigured entry mechanism — the RFC gives the operator lane a real act with real facts. FIELD HYGIENE PASS: struck 2 fields. started_at struck — it is the event's own occurrence time, which every event has by definition, not payload. listen_address struck — RFC 5321 names the mail port (line 3777) and never mentions a listening address, so 192.0.2.10 was supplied by the sweep and not by the source. listen_port's type was Count, which a port is not; corrected to PortNumber. Identity here is the server itself, named by server_domain, since RFC 5321 supplies no instance identifier of any kind.
