## Notes

RECOVERED BY THE RE-SWEEP, and it is the arm the RFC ARGUES AGAINST — the violated-arm shape truncated sweeps lose. Strength: none; 'largely misguided' (4188) and 'advocate that useful functionality not be disabled' (4208-4209) are advocacy, not 2119. Absorbs the drafted UsefulFunctionalityDisabledToDeterFaking (4207-4210), same operator act at different granularity; recorded so it can be split again. Same advocacy recurs at VerificationCommandDisabled — 7.1 refuses the case 7.3 concedes. Rejected names: SenderAddressLockedToUser, ReturnPathForgeryPrevented, FromFieldRestrictionImposed. Screens that would have killed it: altitude tiers, HELO-only charter, the condemned status register. FIELD HYGIENE: struck effective_from. Its value, Tue, 19 May 1998 09:14:07 -0700, is the walk scene's timestamp — but the walk scene stamps the moment a message was received, not the moment a site changed policy, so the field borrowed a real value for a fact RFC 5321 never records: the spec dates no configuration change anywhere. Borrowing is the same fabrication pattern as an invented key, one step subtler; the merge behind ReplacementAddressAssociatedWithMailbox dropped an effective_from for the same reason. Identity: the site, RFC 5321 supplying no configuration key — restricting_site is that identity, not decoration. restriction has no RFC source: 4186-4188 names the effort and never specifies one.
