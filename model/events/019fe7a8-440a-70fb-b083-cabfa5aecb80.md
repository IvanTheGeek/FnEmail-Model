## Notes

SHOULD, and note its unusual shape: the constraint is on the RELATIONSHIP between two configured durations, not on either value alone, so no single event payload can be checked for conformance — it takes both this event's requeue_timeout_days and DeliveryGivenUp's give_up_after_days together. One day and three days are the RFC's illustrative figures (602-604), not requirements. A time-triggered event with no actor issuing a command, which the one-event-per-command target cannot express at all. Both durations are operator configuration, so a preceding administrative event is implied.
