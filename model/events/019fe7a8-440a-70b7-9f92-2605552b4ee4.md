## Notes

Harvested; §4.3.2 line 3115 added by re-sweep, which corroborates 552 as a real DATA-time code rather than only an example. Strength: the floor is a MUST written in capitals in the source — "MUST BE at least 64K" (3519) — and rule 2 keeps the capitals. The consequence is unusual and worth carrying: limit_octets below 65536 makes the EVENT ITSELF a conformance violation, so the same event records both a legitimate refusal and an illegitimate one depending on a field value. Content counts header section PLUS body (3518-3519), which is why this is a different measurement from TextLineLengthExceeded (one line, 1000 octets, excluding the transparency dot). §4.5.3.1.9 offers its codes as examples only; the reply text is operator-configurable and the RFC's own sample carries a period, copied exactly. Two events reachable from the SHOULD at 3523-3526 and cross-referenced rather than claimed: SIZE-extension advertisement (Session Lifecycle) and rejection of a declared size at MAIL (Mail Transaction). Screens: none kills it. Rejected alternative names: MessageTooLarge, ContentSizeLimitExceeded.
