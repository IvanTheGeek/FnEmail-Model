## Notes

Strength: MAY. Lines 1200-1201 name two outcomes in one clause with two different verbs — reject, and return as non-deliverable — and §3.4 never separates them again. Modeled apart because the actor and the clock differ: rejection is the receiving server inside a live session, return is a delivery agent afterward, possibly days later, addressed to the reverse-path. Marked likely because the split is inferred from the two verbs, not stated. Chapter boundary noted rather than resolved: the bounce message this event produces belongs to the Non-Delivery Notification chapter; what is claimed here is only that §3.4 offers this as the alternative to forwarding. Rejected alternative name: UndeliverableMailReturned. Screens: the inbound-only scope and the responsibility-boundary cutoff both kill it outright, and the twelve-slice model has no bounce slice. Citation fixed: inherited candidate cited 1200-1202 for a sentence ending at 1201.
