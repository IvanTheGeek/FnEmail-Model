## Notes

RECOVERED BY THE RE-SWEEP as the violated arm of the SHOULD at 1596-1598. Marked doubtful for a specific reason worth keeping: §3.3 lines 1080-1082 gives servers an explicit MAY to "decline to support the relaying they imply" for source routes, and §3.7.3 lines 1600-1602 extends that rule to gateways — so for the source-route case in particular a refusal may be conforming rather than violating, and the same observable event straddles both arms. That ambiguity is the finding; do not resolve it by choosing one reading. Opposite event: NonstandardAddressFormatAccepted. Related but distinct: SourceRouteIgnoredByGateway is the third outcome for the same input — accept the address and drop the route. Rejected alternative names: AddressFormatRejectedAtGateway, ValidRfc822MessageRefused.

FIELD HYGIENE PASS: struck reply_code (example 501) as a computed value — a reply code is the rendering of a decision, and RFC 5321 assigns no code to a gateway declining a valid address form. §3.7.3 lines 1596-1598 states only the SHOULD to accept; §3.3 lines 1080-1082 grants the MAY to decline without naming a code. The value was minted by the sweep. This event carried no message_ref, so nothing else was struck. Confidence stays doubtful for the reason already recorded — the straddle between the §3.7.3 SHOULD and the §3.3 MAY — and that reason is unaffected by the strike.
