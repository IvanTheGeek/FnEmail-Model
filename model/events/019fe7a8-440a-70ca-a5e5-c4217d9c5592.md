## Notes

MAY on the rejection (1200), MUST NOT on the assumption (1204-1205) — the server may tell the client where to go and may not assume the client listens, which makes the disclosure a fact with no guaranteed consumer. Paired arm, kept separate: RecipientRejectedWithoutAddressInformation (550, nothing disclosed). The unwritten precondition is that somebody moved that mailbox at some earlier time, and this reply is the only visible trace of it. §3.5.3 extends the same shape to VRFY and EXPN, so the event recurs outside a mail transaction and a facilitator should be asked whether that is one event or two. §3.4 1208-1210 adds that implementations supporting 251/551 SHOULD provide a configuration mechanism to disable the disclosure — a Server Configuration event outside this chapter. Rejected alternative names: ForwardPathAdvertised (the §4.2-4.3 sweep's name, which merged 251 and 551 into one event; NOT merged here because 251 accepts custody and forwards while 551 refuses and merely redirects), CorrectedDestinationDisclosed. Screens: 'one event per command', inbound-only, and the condemned status register.

FIELD HYGIENE PASS: struck one field, reply_code (551), as the wire rendering of a decision. The 251-versus-551 distinction the note protects is carried by the event's NAME and by its separation from RecipientRejectedWithoutAddressInformation — 251 accepts custody, 551 refuses and redirects — so a code field was not what kept them apart. §3.4 1200-1206 names 551 and is cited above. suggested_mailbox SURVIVES and is the event's whole content, the thing this refusal says that the paired refusal deliberately does not; its example is now labeled illustrative, because §3.4 discusses the disclosure without ever showing an address. No identity key was present to strike; identity is the refused forward-path.

COLLISION RESOLVED — merged from 3 independently brainstormed records. All three cite §3.4 1200-1206 and the same 551 refusal by the same receiving server, with the same two-field payload under different field names — one state change minted three times. The distinction each record was protecting (551 refusal versus 251 acceptance) is a distinction from a DIFFERENT event, not from each other, so it survives the merge intact.
