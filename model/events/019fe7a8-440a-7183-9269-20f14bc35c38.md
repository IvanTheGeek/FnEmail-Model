## Notes

MUST, twice, binding 'all receivers'. The nine, verbatim from 3384-3392 in source order: EHLO, HELO, MAIL, RCPT, DATA, RSET, NOOP, QUIT, VRFY. Two facts a later reader would otherwise re-derive. First, VRFY is on the mandatory list even though a VRFY exchange is the cleanest 'guest viewed calendar' query in the whole spec — set aside below — so 'queries are not events' rejects the USE of VRFY while leaving this provisioning event standing; they are not the same candidate. Second, the list contains both EHLO and HELO, so the project's HELO-only charter is a scope decision taken against an explicit MUST, not a reading of it. Violated arm carried separately as RequiredCommandLeftUnimplemented. Screens: the HELO-only charter and the Infrastructure altitude tier. FIELD HYGIENE: struck commands. The nine are fixed by the RFC at 3384-3392 and are identical in every instance of this event, so the List carried no information and its example was one entry standing for a constant; the full list is preserved verbatim in these notes instead. server_domain is kept because 3381 lays the MUST on 'all receivers', and a receiver is identified in every session by the domain in its greeting; no session, transaction or connection key was present, and RFC 5321 supplies none.
