# `QueuedRecipientsDischargedOnAcceptance`

Recipients accepted by the server in one transaction were removed from the sending client's queue, while any refused with 452 stayed behind for a later attempt.

## Notes

Inherited candidate 346, kept because it is the handoff seen from the side that is losing the obligation — every other event in this chapter watches the server take custody, and this is the only one that records the client putting it down. That asymmetry is worth a facilitator's attention: a model that only ever draws the receiving side cannot show responsibility leaving anywhere. ⚠️ Citation hazard carried forward from the inherited notes and re-checked: the sentence spans a page break, beginning 'If the server is able to accept the message, then at least these 100' at line 3582 and continuing at 3591 with the page footer between, so the line-3591 fragment is quoted rather than the joined sentence. The inherited candidate also carried discharged_count 100 and deferred_count 45; both are dropped here as computed values under the only-facts rule — the lists carry the same information as facts. The RFC's convergence argument the counts were standing in for is worth keeping in prose instead: because at least 100 recipients are discharged per successful attempt, a large recipient list terminates. Screens: inbound-only scope. ⚠️ FIELD HYGIENE PASS 2026-08-09 — two fields struck. queue_entry_id: RFC 5321 names no queue identifier of any kind, and the §4.4 ID clause that the audit allows a queue id to live in is the RECEIVER's trace clause (line 3336), written into a Received: stamp — not a handle on a sending client's queue entry, which §4.5.3.1.10 line 3591 refers to only as 'the SMTP client's queue' with nothing naming its rows. The example f2C8D14 is this project's own minted queue_id (commit 6acfc68) and is absent from the RFC. Identity here is the two address lists: the RFC's own unit of account in this passage is the address, discharged or retained (3591, 3592). discharged_at: struck as the event's own occurrence time. Both surviving fields are Lists, as the inherited record had them.
