## Notes

SHOULD strength (3716-3718). The list is per-HOST state that outlives every message and every session — the clearest example in the chapter of a fact that only exists over time. Its purpose is cost avoidance, spelled out at 3739-3744. Rejected name: UnreachableHostRecorded (named in an inherited span's cut pile). Opposite event: HostReachabilityRestored, which the RFC never states. Reading the list before attempting delivery is a query and is in set_aside; this is the write. This is a status-shaped event on a host, which the condemned status/phase register would have killed and which the brief explicitly readmits; both authors use status events in their own worked material. Screens: inbound-only scope, condemned status register. ⚠️ FIELD HYGIENE PASS: STRUCK host_address — the RFC's sentence is scoped to HOSTS, twice ("a list of hosts it cannot reach", "corresponding connection timeouts", 3716-3718), and an address is an address-resolution result belonging to that chapter. Note the deliberate contrast with QueueFlushTriggeredByPeerContact, which keeps an address because there the RFC says "address" in its own words at 3725-3727 and 3783-3785. STRUCK marked_at as a bare occurrence stamp. connection_timeout_seconds stays because 3717-3718 pairs the timeout with the host explicitly, and its example is the RFC's own: "even a one-minute timeout per connection" at 3741-3742.
