## Notes

RECOVERED BY THE RE-SWEEP as the violated arm of the SHOULD at 3186-3188; the inherited set carried only the configuration event (idx 195) and none of the per-message consequences. SHOULD, so this is conforming-but-discouraged, and the RFC says exactly what it costs at 3184-3186: comparability across hops, which is what makes SlowRelayDetected possible at all. That makes this event and SlowRelayDetected a matched pair — the first destroys the input the second needs. 'rather than time zone names of any type' (3187-3188) is unusually absolute for a SHOULD and forecloses the obvious defense that some zone names are unambiguous. The compliant escape is at 3201-3202: put the name in a comment *alongside* the offset, which loses nothing. Real data per rule 8: 'Tue, 19 May 1998 09:14:07 PDT' is the project's standing timestamp with the offset swapped for the name it corresponds to, so the two forms can be compared directly.
