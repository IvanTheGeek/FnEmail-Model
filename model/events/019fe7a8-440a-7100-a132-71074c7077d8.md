## Notes

Strength: MAY on the forwarding behavior (1191-1192); the provisioning act itself carries no RFC 2119 keyword and is never specified anywhere in the document. The RFC never says how a server became "aware of an address change" — this event names the moment that awareness was created, and it is the unwritten precondition of every 250/251/551 event below. Sibling, deliberately NOT merged: MailboxRelocationRecorded — lines 1164-1167 name two causes (enterprise consolidation, person moved) with different data and different disclosure sensitivity, and line 1183 ("final address may not even be reachable by the sender") is a property of the relocation case only. Third sibling with a different actor: MailForwardingRuleCreated (a mailbox owner, not an administrator). Opposite: no de-provisioning event is offered because the RFC states no lifetime for a forwarding entry — a future reader must not read that silence as a ruling; the nearest thing is ForwardingEntryRetiredOnAssumedClientUpdate, which is a violation, not a normal retirement. Rejected alternative names carried from the merge: AddressChangeRecorded, ConsolidatedAddressMapped. Project screens that would have killed it: the four altitude tiers (this sits below the Protocol tier), the inbound-only scope, and the responsibility-boundary cutoff — provisioning happens long before any session opens. Citation fixed: inherited candidate cited lines 1164-1167 for a quote that ends at 1165.

⚠️ FIELD HYGIENE PASS (fields and notes only): nothing struck — both fields were already real RFC values, sourced at rfc5321.txt:5114 and rfc5321.txt:4895. No identity key was added or invented: a grep for "session id", "transaction id" and "connection id" over rfc5321.txt returns nothing, so RFC 5321 names none of them, and none is needed here — a provisioning record is identified by the published mailbox it redirects. This is one of only three events in the chapter to survive the pass with its payload intact, and the reason is instructive: it never touched a wire, so no sweep felt the pull to hang a session or transaction key on it.
