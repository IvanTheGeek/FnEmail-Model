## Notes

RECOVERED BY THE RE-SWEEP. The violated arm of the SHOULD NOT at 3233-3234, named as a precondition in the inherited ReturnPathHeaderStrippedBeforeDelivery notes but never given a row by any sweep. It is worth its own event because it is the upstream cause of two downstream repairs in this chapter — the delivery server's MAY to strip (3237-3238) and the relay's MAY to remove and rebuild (3229-3231) — and both of those exist only because this event happens. A model that carries the repairs but not the cause cannot explain why the repairs are permitted. SHOULD NOT, so a conforming-but-sloppy originator is the ordinary case, not an attack. Screens: inbound-only scope kills it outright; the responsibility-boundary cutoff never sees it, because it happens before any inbound session opens. ⚠️ FIELD HYGIENE PASS 2026-08-09 — one field struck. message_id: RFC 5321 supplies no message identifier — §4.4's ID clause (line 3336) is optional and belongs to a receiver's Received: stamp, which by definition does not exist yet at origination, and msg-id is RFC 5322's; f2C8D14 is this project's minted queue_id value. Identity here is the offending header value itself, pre_existing_return_path, together with the system that emitted it.
