## Notes

Carried from #69, but SPLIT: the MUST NOT arm the inherited candidate had folded in is now its own event, InvalidSourceRouteGenerated, because two different strengths sat on one record and a merged event cannot carry both honestly. Strength here: SHOULD NOT with an explicit escape hatch - 'except under unusual circumstances' (1428) - so a conforming client CAN generate one and the RFC never says what an unusual circumstance is. HOTSPOT on that undefined escape hatch. The source-route syntax is valid against the 4.1.2 ABNF (Path = "\<" [ A-d-l ":" ] Mailbox ">", line 2264) and against the RFC's own example at 1970. Rejected names: SourceRoutedPathSubmitted, SourceRoutedForwardPathSent. Screens: inbound-only scope, HELO-only charter. --- FIELD HYGIENE: struck relay_hops and final_destination - both are readings of the forward-path under the 4.1.2 grammar (Path at 2264, A-d-l = At-domain *( "," At-domain ) at 2266), so they are derived values, and the method puts derived values in read models. Value re-based on the RFC's own source-route example at 1944; source routes are the one subject Appendix D.3 does not walk, so this chapter uses 4.1.1.3's scene for them.
