## Data

**No data.** The method sanctions this: *"If an event has no meaningful payload beyond its identity (e.g., a simple state transition), it is fine to have no fields or just the identity key."* It also warns, of a different case, that *"An event without fields is an opaque label"* — both are recorded here rather than reconciled, because reconciling them is a later step's work, not Brain Storming's.

## Notes

Merged SessionEndRequested (§3.8 sweep) and QuitReceived (§3.1 sweep). A third candidate, SessionClosureRequested (§4.1.1.x sweep), was SPLIT rather than merged: it fused three acts — the QUIT, the 221 and the close — which this chapter carries as SessionEndRequested, ClosingReplySent and TransmissionChannelClosed. Rejected alternative names: QuitReceived, SessionClosureRequested, QuitIssued. The one-event-per-command design target would collapse all three back into one postcondition; they are kept apart because the middle act is observable without the third — a server that sends 221 and then hangs is a real thing. MUST-strength on the client side comes from §4.1.1.10, not from §3.8, which is descriptive. Note §4.1.4 lines 2530-2532: QUIT is owed 'even when no session opening command was sent and accepted', so a session that never greeted still owes one — a path the twelve-slice model has no room for, and the variant most likely to be missed. Its transaction consequence is carried in the Transaction chapter as MailTransactionAborted with aborting_command QUIT. FIELD HYGIENE PASS: struck 3 fields, event is now FIELDLESS, and this is the cleanest example in the chapter of the method's sanctioned fieldless outcome. session_id struck: no such key in RFC 5321. client_address struck: the peer belongs to the channel and was recorded at TransmissionChannelOpened. requested_at struck as the event's own occurrence time. What is left is exactly right — §4.1.1 lines 1777-1781 names QUIT as one of three commands 'specified as not permitting parameters', so the command carries no data whatsoever, and an event recording it can only be a bare state transition identified by its position as the last command in the session.
