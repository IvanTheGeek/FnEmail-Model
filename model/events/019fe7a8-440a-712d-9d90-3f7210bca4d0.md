## Notes

RECOVERED BY THE RE-SWEEP. The violated arm of the MUST at 1692 — the inherited candidates carried only the honored arm. Not the same event as AliasExpanded, which also leaves the return path alone: there the omission is correct and definitional, here it is a MUST broken, and the difference is what the pseudo-mailbox was defined as (MailingListDefined.expansion_kind). That distinction is exactly the kind the prompt warns against collapsing — a refusal is not an acceptance, and a permitted absence is not a violated one. Rejected alternative names: ReturnPathRewriteOmitted, ListBehavedAsAlias, BackwardPointingAddressNotChanged. Its downstream consequence is a separate event, ErrorMessageReturnedToOriginator, because it lands days later at a different actor. Marked likely rather than certain because the RFC never contemplates the failure in words — it is inferred from the MUST having a negative arm at all, which is the standard Step 1 move and should be flagged as inference, not text. Screens: the consumer test G1 kills it instantly (nothing consumes it), and the condemned status register would reach it by shape. FIELD HYGIENE PASS: expected_administrator struck — 1 field. It was owner-staff@foo.com, the value MailingListDefined.administrator already holds for this pseudo-mailbox, looked up and set beside the reverse_path so the two could be compared; that comparison is what makes the record a violation, and a comparison is a fold over events, which the method sends to a read model. It is also a counterfactual: it names an address that was never written anywhere, so nothing in the world carries it at this moment. reverse_path stays for the opposite reason — its survival IS the event, not context carried along. queue_id kept on the §4.4 ID-clause warrant.
