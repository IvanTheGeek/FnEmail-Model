## Notes

Inherited from candidate 233; citations checked and correct. The generic parent of every 4yz refusal in this chapter (452 recipient overflow, 455 parameters, 451 processing error) and kept as its own event because the RFC treats the severity class itself as carrying meaning — the client's whole retry behavior forks on the first digit and on nothing else. The RFC admits its own ambiguity in so many words, "It is difficult to assign a meaning to 'transient'", and offers only a rule of thumb, so the 4yz/5yz split is a judgment the receiving implementation makes rather than a fact it reads off — a genuine hotspot if this chapter is ever drawn. Strengths: SHOULD for the client retrying; lowercase "should" at 2670-2671 for returning to the beginning of the command sequence. Merged sibling, not given a row: CommandSequenceRestarted (the client re-opens at the start). Deliberately NOT merged with PermanentFailureReturned — a transient refusal is not a permanent one, and collapsing them into one event with a code field would hide the only distinction the client acts on. CommandRetryAttempted (raw candidate 235) is the client-side consequence and is handed to whichever chapter owns retry and queueing. Screens: the condemned status register (this is a status-shaped event, and both authors use those).

FIELD HYGIENE PASS (chapter 14): three of four fields struck. session_id struck — RFC 5321 names no session, transaction or connection identifier, and f2C8D14 is nowhere in the RFC; identity here is position in the session. reply_code struck as the rendering of the server's decision: lines 2557-2559 assign the number to the automaton, but on the emitting side it is the decision written out, and the 4yz class the client actually forks on is already in the event's name — keeping the code would also have made the transient arm look like a payload difference when it is a naming difference. failure_text struck: "the text is for the human user" (2558-2559). command_verb KEPT: the command was refused, so no accepted-command event records it and this is the only capture of what drew the refusal.
