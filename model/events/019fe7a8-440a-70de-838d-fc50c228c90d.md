## Notes

Recovered by the re-sweep — it was explicitly named in the inherited span notes as cut for the thirty-two-event ceiling, never modeled. No normative keyword: the RFC describes it as what a typical system does. It is a priority state change on a queue entry and it is the counterweight to the periodic model — without it every message waits for a cycle. A two-field event, close to the kit's fieldless case; the kit's own tension applies (fieldless events are legitimate, but an event without fields is an opaque label), and it is not resolved here. Sibling: QueueRunStarted, which is what this event lets a message skip. Screens: inbound-only scope and the altitude tiers, which would file a queue priority flag as Infrastructure. ⚠️ FIELD HYGIENE PASS: STRUCK flagged_at — a bare restatement of the event's own occurrence time, which the stream carries and which no rule in RFC 5321 measures from. What is left is the identity key alone, which the method sanctions explicitly, and the note above about the kit's tension now applies for real rather than as a near miss. queue_entry_id kept on §4.4's ID-clause ground (rfc5321.txt:3336); f2C8D14 is this project's minted value, not the RFC's.
