## Notes

Inherited (candidate 26), with a finding added by the re-sweep that changes how it must be read. §4.1.4 lines 2496-2500 declares the RFC 821 example showing '550 access denied to you' in response to EXPN INCORRECT unless an EHLO preceded it or the denial rests on the client's IP address or on authentication — and §3.5.1 line 1322-1323 is that same example, carried forward into RFC 5321 with no cross-reference. So the RFC contains its own example and, sixty pages later, the conditions under which that example is wrong. This event therefore has a precondition the §3.5 span never states: either a session already identified, or an IP-based or authentication-based access decision. That is the strongest argument in the chapter for AddressDiagnosticsRestrictedToAuthenticatedRequestors being a real upstream event rather than a nicety. Strength: none in §3.5.1 — the behavior is taught purely by example; the §4.1.4 sentence uses no 2119 keyword either. Reply text quoted with the RFC's own capitalization and final period at 1323, and in lowercase at 2500 where the RFC itself writes it that way — rule 2, both times. Rejected alternative names: MailingListExpansionRefused, ListAccessRefused, ExpnRefusedForPolicy. Configuration arm: MailingListAccessRestricted. Which screen would have killed it: the consumer test (G1), 'one event per command', the capture/decision lens. FIELD HYGIENE PASS: struck reply_code (550).
