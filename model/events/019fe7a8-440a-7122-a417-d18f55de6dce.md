## Notes

RECOVERED BY THE RE-SWEEP. The capped sweep spotted the implication in ReturnPathInsertedByOutboundGateway's notes — "which implies a prior event: TransportCapabilityRecorded, an administrator asserting that the far-side transport keeps envelope senders separately" — and had no slot for it. The RFC says "unless it is known that" and never says how it becomes known, which is precisely why this is a 🟥 hotspot rather than a well-specified event: a normative exception hangs on a fact with no stated provenance. Marked doubtful because the RFC specifies no such act; the event is inferred from the exception's existence, and a facilitator may reasonably reject it on those grounds. If kept, it is durable configuration on a per-destination basis, not per-message — hence stream_root Next-Hop Destination rather than Message; Server Configuration was the alternative considered and rejected, because the fact is about the far side, not about this server. Rejected alternative names: TransportCapabilityRecorded, FarSideEnvelopeSupportAsserted. The act of CHECKING this record before deciding is a read and is set aside. Which project screen would have killed it: all of them — the current model has no seat for an operator actor at all.

FIELD HYGIENE PASS: struck two Boolean fields, maintains_envelope_sender (true) and uses_internet_domain_addresses (true). Both restate the event's own name and meaning: the card fires only when both conditions hold, so a Boolean that is always true when the event exists is a derived value with no information in it. If a facilitator wants a card that can record the absence too, the answer is a differently named event, not a Boolean — deciding that is a later step's job. What identifies the record instead: the far-side transport and the gateway it sits behind, which together are the per-destination configuration key §4.4 lines 3263-3266 presupposes without naming. No message_ref was present. Confidence stays doubtful for the reason already recorded — the RFC specifies no act of recording — and the strike does not deepen it.
