## Notes

Merged ServiceExtensionsOffered (§3.2 sweep) and ServiceExtensionsAdvertised (§4.1.1.1 sweep). Rejected alternative names: ServiceExtensionsOffered, ExtensionListPublished, EhloResponseSent. CITATION ERROR FOUND AND FIXED in the inherited candidate: its ehlo_greet example was 'foo.com Simple Mail Transfer Service Ready', which is the 220 greeting text, not the ehlo-greet production — D.1 line 4888 shows '250-foo.com greets bar.com', so per the ABNF at lines 1841-1844 the Domain is foo.com and the ehlo-greet is 'greets bar.com'. Real keyword values are the RFC's own at D.1 lines 4889-4892: 8BITMIME, SIZE, DSN, HELP. This is the event that makes MAIL's mail-parameters and RCPT's rcpt-parameters meaningful at all — §4.1.1.3 makes the advertised set the client's permission boundary, and §4.1.1 lines 1777-1781 extends the same boundary to parameters on RSET, DATA and QUIT. Strengths: MUST for the content, MUST for case-insensitive recognition, MAY for listing private-use commands, MUST NOT for returning it to a HELO. That last one means this event cannot occur in a HELO session, so the HELO-only charter is the screen that kills it; the one-event-per-command target fights it too, since it is the second thing one EHLO produces. Over-time counterpart cut for the cap: ServiceExtensionEnabled, the administrator act that puts a keyword on the list months earlier (stream_root Server Configuration) — the spec constrains what is advertised but never says how a server came to offer anything. FIELD HYGIENE PASS: struck 3 fields. session_id struck — no such key; identity is the server publishing plus the channel it publishes on. greets_domain struck as a parse of the greet line that also duplicates the claim already recorded at ClientIdentityDeclared. ehlo_greet struck as decorative text: §4.2 lines 2610-2612 does not license a client to act on the text of a 250, so the greet line is unread, and the fact this event exists to carry is the keyword list. The citation-error correction above is kept even though the field it corrected is gone — it records what the inherited candidate got wrong and how the RFC's own D.1 lines settle it.
