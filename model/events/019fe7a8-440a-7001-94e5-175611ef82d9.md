# `LocalAliasAppearedInTransaction`

A name that was not in FQDN form — a local nickname or an unqualified name — appeared in an SMTP transaction, which the spec forbids.

## Where RFC 5321 says so

| Section | Lines | Text |
|:--|:--|:--|
| §2.3.5 | 711-712 | *"A domain name that is not in FQDN form is no more than a local alias. Local aliases MUST NOT appear in any SMTP transaction."* |
| §2.3.5 | 718-719 | *"Local nicknames or unqualified names MUST NOT be used."* |

## Notes

MERGED and RENAMED from the inherited LocalAliasRejected (confidence doubtful). The inherited notes were right and the name was wrong: the MUST NOT is aimed at the name *appearing*, not at the server's response, and §2.3.5 licenses no reply code, so the fact this span certifies is the violation. Rejected alternative names: LocalAliasRejected, UnqualifiedNameUsed, LocalNicknameUsed. Strength: MUST NOT, stated twice within eight lines (711-712 and 718-719) — belt and braces on one rule, not two; a reader who models both gets a duplicate. Opposite/sibling event: UnqualifiedDomainNameRefused, carried separately because a refusal is not the violation. CITATION CORRECTION on an inherited candidate: LocalAliasRejected cited this quote as §2.3.5 lines 709-712; the quoted sentences begin at 711 — 709-710 are the FQDN definition, a different sentence. Two stated exceptions live at 722-726 (the EHLO name) and 735-737 (postmaster unqualified, a MUST-accept), and both belong to other chapters. Which project screen would have killed it: the condemned status/phase register and the consumer test (G1). ⚠️ FIELD HYGIENE PASS: struck session_id (example f2C8D14). RFC 5321 names no session, transaction or connection identifier anywhere — a grep for all three forms over the file returns nothing — and f2C8D14 appears nowhere in the body or in Appendix D; it is this project's own minted queue-id example (commit 6acfc68) and had no business here. What carries identity on this event is the transaction's position in the session — which command carried the offending name — so offering_command is kept as identity rather than as payload, and 'RCPT TO' is the RFC's own command spelling at 5010. offered_name stays illustrative: RFC 5321 gives no example of a local alias, which is itself worth noticing.
