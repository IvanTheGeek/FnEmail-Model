# `RecipientBuffered`

## Notes

MERGE of three raw candidates naming one state change: RecipientAdded (§4.1 sweep, 'appends to the forward-path buffer'), RecipientBuffered (§4.5.3 sweep, 'recipients buffer'), and ForwardPathStored, which the §3.1-3.3 sweep folded into RecipientAccepted while recording that 'the storing is the actual state change, the 250 is only its announcement' and that 'a second pass could legitimately split it'. This is that split. Rejected alternative names: RecipientAdded, ForwardPathStored, ForwardPathAppended. A recipient count was considered as a field and DROPPED as computed — it is derivable from the stream, and the kit forbids computed values on events. This is the precondition nobody writes down: §4.5.3.1.10 states as established fact that an overflowing server 'has at least 100 successful RCPT commands in its recipients buffer', so the buffer is a real accumulating structure whose every entry got there by an event — if it is never written it can never be read. Killed by three screens: 'one event per command' (a second event on the same RCPT), the consumer test G1, and the capture/decision lens. All named, none applied. Mirror event: ReversePathBuffered.

FIELD HYGIENE PASS: struck two fields, session_id and transaction_id — fabricated in key and in value alike. RFC 5321 names no session or transaction identifier anywhere (grep returns nothing) and f2C8D14 is this project's own minted queue-id example from commit 6acfc68, absent from the RFC body and from Appendix D. Identity here is the forward-path just appended, and the buffer it lands in belongs to the transaction open on the channel. The sweep that dropped a recipient count as computed had the rule right and then applied the opposite rule to the identifiers; the same discipline removes them. This event and ReversePathBuffered together are what let the envelope be folded rather than copied, which is why the discarded-value fields on TransactionBuffersCleared and the reverse_path and recipients fields on MailTransactionConfirmed could be struck as derived.
