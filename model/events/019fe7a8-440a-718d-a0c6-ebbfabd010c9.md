## Notes

RECOVERED BY THE RE-SWEEP. The SHOULD at 4378-4379 is laid on IMPLEMENTATIONS, not on sites — a different actor from RelaySourceAuthorized, on a different timeline, and the raw set carried neither. Same doubled shape as the version-announcement switch at §3.1 967-969: the implementer builds the capability, the operator then uses it, and on a server where the first never happened the second cannot occur. Violated arm, and it is not hypothetical: an implementation shipped without relay filtering leaves every deploying site an open relay while remaining silent about it — the SHOULD is the only thing standing between §7.9's first paragraph and its second.
