## Notes

MERGED from six raw candidates that all named the same state change — the bounce leaving — under different names and citations: UndeliverableMailNotificationSent (§3.6.3), UndeliverableMailNotificationSent (§4.4), NonDeliveryNotificationSent (§6.1), NotificationSentWithNullReversePath (§4.5.5), SubsequentFailureNotificationReturned (§3.3 1144-1150, deferred recipient verification), DeliveryFailureReportGenerated (§4.1.1.4 2047-2049). Also rejected as names: MessageReturnedAsNonDeliverable, MessageBouncedAsUndeliverable, NonDeliveryNoticeReturned, NonDeliveryNotificationReturned, MessageReturnedAsUndeliverable, SubsequentFailureNotificationReturned. The composition half is split off into NonDeliveryNotificationComposed; only the mailing is here. recipient_source is a real field because §6.1 3973-3974 names TWO sources — the envelope return path and the Return-Path: header line — and which one was used is a fact, not a derivation, once the envelope is gone. NOT merged, and each cross-referenced instead: (a) MessageReturnedAsUndeliverable on exhausted MX candidates, §5.1 3932-3934 — a routing failure, belongs to the address-resolution chapter, though it produces the same thing on the wire; (b) MessageReturnedAsUndeliverable for garbled 8-bit content, §2.4 913-915 — a MAY, a content judgment, belongs to the conformance chapter; (c) ErrorMessageReturnedToListAdministrator, §3.9.2 1723-1727 — the same bounce landing somewhere else because a list rewrote the backward-pointing address, belongs to the list chapter; (d) NonDeliveryNotificationReturned, §4.2.5 2953-2957 — the SENDING client's give-up notification, which is an originator's act and not a receiver's, kept apart on the brief's warning that a relay's send is not an originator's. One vocabulary note worth keeping: §6.2 4018-4020 calls this act "bounced" while §6.1 and §3.6.3 call it a notification — one document, two vocabularies for one event. Which screen would have killed it: the inbound-only scope decisively, since this event SENDS mail, plus the responsibility-boundary cutoff.
