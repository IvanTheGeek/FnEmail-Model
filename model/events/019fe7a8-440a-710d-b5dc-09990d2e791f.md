## Notes

RECOVERED BY THE RE-SWEEP — the violated arm of the chapter's only MUST NOT, stated twice in identical words. The merged list carried the honored arm implicitly (the server keeps forwarding regardless) and the far-side arm (AddressBookEntryUpdated), but nothing for the server that ACTS on the forbidden assumption. Doing so is the specific harm the MUST NOT guards against: the entry disappears, later mail from clients that never updated is refused or lost, and the server has no way to detect its own error because the assumption was unobservable in the first place. Marked DOUBTFUL: the RFC names the forbidden BELIEF, not any particular act taken on it, so retiring the entry is one plausible instantiation among several (others: ceasing to emit 251, narrowing the entry to unseen clients). Recorded as a violation event rather than dropped because the brief is explicit that the violated arm is where truncated sweeps lose events, and because a MUST NOT stated twice is a strong signal implementers were doing this. Rejected alternative names: ClientUpdateAssumed, ForwardingEntryPrematurelyRemoved, AddressChangeConsideredPropagated. Screens: the capture/decision two-kinds lens has no place for a violation; the twelve-slice model has no forwarding-entry lifecycle at all; the altitude tiers put it below Protocol.

⚠️ FIELD HYGIENE PASS (fields and notes only): struck one field, assumed_from_reply_code (251) — the rendering of a decision, and here the strike is forced by the RFC's own symmetry: the MUST NOT this event violates is stated TWICE in identical words, at rfc5321.txt:1194-1196 for 251 and rfc5321.txt:1204-1206 for 551, so the code distinguishes nothing about the violation. The forbidden belief is about the client, not about which reply carried it, and a code field would have implied the server tracked a distinction the spec does not draw. What survives is the entry that was dropped and what it pointed to — the mailbox is the identity, the replacement is the fact that makes the retirement a loss. Confidence left at doubtful for its original reason, that the RFC names the belief and not the act; the strike does not change it, since the field was never part of the case.
