## Notes

Harvested, WITH A CITATION FIX that changes what the event carries. The sweep flagged "⚠️ Reply code is not given in this span; 550 is conventional and flagged as a guess." The re-sweep found it: §4.3.2 line 3117 names 450 and 550 explicitly as "rejections for policy reasons" for DATA. So the code is now cited — and the pair matters, because 450 and 550 are a transient and a permanent refusal for the same reason, which means a facilitator may want MessageRejectedByPolicyTemporarily and MessageRejectedByPolicyPermanently as separate events; their downstream client behavior differs (see DeliveryResponsibilityDeclinedTemporarily versus …Permanently). "policy or other reasons" is the widest permission in the document — every anti-spam, reputation, content and rate decision a real server makes lives inside those five words, and RFC 5321 spends no more on it. Occurs strictly AFTER the 354, so the server has already accepted and read the content it is refusing. Screens: the decision-model lens would welcome this one, which makes it a useful control — it is the candidate the project's own screens keep, sitting beside events they would not.

FIELD HYGIENE PASS: struck four of five. transaction_id is fabricated; the forward paths carry identity for a refused transaction, since no queue id is stamped when nothing is accepted. reverse_path is struck as carried by the MAIL event and not what this refusal is about — unlike DeliveryResponsibilityAccepted, a refusal creates no notification obligation that would need it. reply_code is struck as a rendering: the re-sweep's fix stands and is preserved above, but citing 450 and 550 establishes the wire codes, not data the server holds, and the transient/permanent split those codes carry is a naming question a later step must settle by splitting the event, exactly as the note proposes. reason_text is struck as invented: RFC 5321 supplies no reason vocabulary at all — "policy or other reasons" is the whole of it — so any value in that field is an unsourceable guess, and the note above already says the document spends no more than five words here.
