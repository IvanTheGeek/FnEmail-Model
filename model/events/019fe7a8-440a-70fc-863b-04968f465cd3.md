## Notes

Recovered by the re-sweep: the inherited ExtensionFallbackTimeoutElapsed named it and declined to carry it because "if one is available" (601) makes it conditional and because the transformation itself is not described in §2.2.3. Both objections are real and neither is a reason to omit the event — the timeout elapsing and the message actually going out downgraded are different facts, and only the second one changes what the recipient receives. Conditional, so the arm where no unextended format exists is a separate outcome and lands on MessageBouncedBeforeFallbackAttempted or DeliveryGivenUp. Rejected name: MessageTransmittedWithoutExtension. Screens: inbound-only scope, HELO-only charter, and the altitude tiers, which would file a content transformation below the model. ⚠️ FIELD HYGIENE PASS: NOTHING STRUCK. abandoned_extension is the fact that makes the event mean anything — what the recipient did not get — and 8BITMIME is the RFC's own token at rfc5321.txt:922; next_hop_host is the party the downgrade was performed for. No timestamp and no session or transaction key: RFC 5321 supplies neither, and the queue entry carries identity. queue_entry_id kept on §4.4's ID-clause ground (rfc5321.txt:3336); f2C8D14 is this project's minted value, not the RFC's.
