## Notes

Carried from the inherited candidate. Strength: MUST, and the RFC states it TWICE within eight lines (3844-3846 and 3851-3852) — belt and braces on one rule, not two rules; a reader who models both gets a duplicate event. The first statement is the wider one: it also covers the implicit MX being unusable, which the restatement drops. 'Usable' is never defined anywhere in §5: 🟥, and it is the definition on which this whole branch turns. Feeds RoutingErrorReported. Sibling that is NOT this: ImplicitMailExchangerAssumed, which fires on an empty list, not on unusable records. Feeder: MailExchangerTargetFoundUnresolvable, if a client chooses to treat an unresolvable target as unusable — which the spec does not say. Which project screen would have killed it: the four altitude tiers. ⚠️ FIELD HYGIENE PASS: struck forward_path — the branch at 3844-3846 turns on the domain's records, not on any one recipient, so the recipient is a read-model join and not a fact this event certifies; the same strike was applied to TargetDomainFoundNonExistent. unusable_exchangers is kept: it is an observation of what was found and rejected, not a computation, and because 'usable' is undefined it is the only record of what the client actually judged. Its example is labeled illustrative because RFC 5321 supplies no exchanger host name outside D.3's xyz.com and foo.com, neither of which is an unusable one. No fabricated identity key was present to strike.
